# Data sources

Most files in `data/` are committed. The data-center seed inputs below are **not**. They are
third-party compilations, so this repo doesn't republish them. To reproduce the data-center
enrichment (`enrich_datacenters.py`), get each one from its source and put it at the path shown.

## FracTracker Alliance data centers: `data/Data_Centers_Database.xlsx`

- **What it is:** FracTracker's in-progress tally of permitted, existing and proposed US
  data centers (1,712 rows when this pipeline used it, accessed October 2026).
- **Where to get it:** https://www.fractracker.org/data-centers/. The data dictionary is at
  https://docs.google.com/spreadsheets/d/1KVab4niu8X_GGne3WyyH_CdTP9Bt4uJSe6iK0fu9C48/edit
- **What the script reads:** sheet `DB_Output_V2`. The other data sheet has unresolved
  `IMPORTRANGE` formulas.
- **Required citation:** per the dataset's terms, any public-facing use must cite it as:

  > Data provided by FracTracker Alliance ([Year Data Was Accessed]). Accessed via
  > https://www.fractracker.org/data-centers/

- **Terms:** FracTracker keeps all rights in the compilation and database structure, and use
  must be consistent with its mission. The full terms are in the workbook's `README` sheet
  and at https://www.fractracker.org/terms-of-service/.

## trackdatacenters.com facilities: `data/trackdatacenters_seed.csv`

- **What it is:** 178 facilities listed on https://trackdatacenters.com that weren't already
  in the FracTracker list (accessed October 2026). It's used only as a seed list. The pipeline
  takes the facility name and place (city, county, state) from it, and no other field.
- **Columns:**
  - `facility_name`, `city`, `county`, `state`: from the trackdatacenters.com listing.
  - `lat`, `long`: our own Nominatim geocodes of the city, or the county when the city was
    unknown. `location_confidence` says which.
  - `tdc_verdict`: `new` (133 rows), or `possible_duplicate` (45) of the FracTracker row
    named in `closest_existing_seed`.
  - `seed_source_url`: the trackdatacenters.com page for the facility.
- **How to rebuild it:** no script in this repo builds this file. Every row's source page is
  in `seed_source_url`. To rebuild, collect those listings again, drop facilities already in
  the FracTracker list, and geocode the city or county.
- **Citation:** trackdatacenters.com doesn't publish a preferred citation that we know of.
  Cite it as "trackdatacenters.com, accessed October 2026", and check the site's terms
  before any public-facing use.

## Local-only pipeline files (gitignored)

These are regenerated by running the pipeline, and doing so costs API money:

- `data/datacenter_searches.jsonl`: cached Perplexity searches, one per facility. About
  20 MB, and about $13.77 to regenerate for 1,890 facilities.
- `data/*.raw.jsonl`: raw Perplexity and Claude responses for every row, kept for auditing.
- `data/*.bak`: backups made before in-place edits of the output CSV.
